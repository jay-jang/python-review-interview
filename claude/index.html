PART 1

코드 리뷰 인터뷰란

면접관은 "버그를 몇 개 찾았나"보다 무엇을 먼저 보고, 어떻게 우선순위를 매기며, 어떻게 말하는가를 봅니다.

면접관이 실제로 평가하는 것

평가 항목보는 것좋은 신호
정확성 (Correctness)버그, 엣지 케이스, 예외 처리빈 입력·None·경계값·동시성을 스스로 떠올린다

설계 감각책임 분리, 결합도, 확장성, API 형태"이 함수는 I/O와 계산을 같이 해서 테스트가 어렵다"

커뮤니케이션톤, 우선순위, 근거 제시Blocking vs Nit 구분, 질문형 코멘트, 칭찬도 포함
흔한 감점 요인 스타일(공백, 따옴표) 지적만 10개 하고 실제 버그를 놓치는 것. 스타일은 도구가 잡는다고 말하고 넘어가는 것이 오히려 시니어다운 태도입니다.

리뷰 진행 순서: 큰 것 → 작은 것

  1. 맥락 파악 (1~2분) — 이 코드의 목적은? 입력/출력은? 호출자는 누구? 모르면 질문한다.
  2. 정확성 — 로직 버그, 엣지 케이스(빈 값, None, 0, 음수, 유니코드, 대용량), 예외 경로.
  3. 안정성/보안 — 리소스 정리, 타임아웃, 재시도, 인젝션, 비밀정보 노출.
  4. 설계 — 함수/클래스 책임, 중복, 추상화 수준, 의존성 방향, 공개 API 형태.
  5. 성능 — 복잡도, 불필요한 반복/복사, I/O 패턴. (측정 없이 과도한 최적화 요구는 금물)
  6. 가독성/관용구 — 네이밍, Pythonic 표현, 타입 힌트, docstring.
  7. 테스트 — 무엇이 테스트되지 않았는가?
  8. 스타일 — 린터/포매터로 자동화 제안.

PART 2

Python의 핵심 모델

대부분의 "이상한 버그"는 이름(name)과 객체(object)의 관계, 가변성(mutability), 스코프를 잘못 이해한 데서 나옵니다. 리뷰어는 이 모델로 코드를 읽어야 합니다.

모든 것은 객체, 변수는 "이름표"

  • 변수는 값을 담는 상자가 아니라 객체에 붙은 이름(참조)입니다.
  • =는 복사가 아니라 바인딩입니다. b = a는 같은 객체에 이름을 하나 더 붙일 뿐.
  • 모든 객체는 정체성(id), 타입, 값을 가집니다. is는 정체성, ==는 값(__eq__) 비교.
  • 함수 인자 전달은 "call by sharing(객체 참조 전달)": 함수 안에서 객체를 변경하면 호출자에게 보이고, 이름을 재바인딩하면 보이지 않습니다.
참조 공유
a = [1, 2, 3]
b = a          # 같은 리스트 객체
b.append(4)
print(a)       # [1, 2, 3, 4]
print(a is b)  # True
변경(mutate) vs 재바인딩(rebind)
def mutate(xs):
    xs.append(99)      # 호출자의 객체가 바뀜

def rebind(xs):
    xs = [0]           # 로컬 이름만 바뀜

data = [1]
mutate(data); print(data)   # [1, 99]
rebind(data); print(data)   # [1, 99]
+= 의 함정: 가변 객체는 제자리 변경
t = [1]
u = t
t += [2]     # list.__iadd__ → 제자리 변경
print(u)     # [1, 2]

s = (1,)
v = s
s += (2,)    # 튜플은 새 객체 생성
print(v)     # (1,)

가변(Mutable) vs 불변(Immutable)

불변 (hashable 가능)가변 (unhashable)리뷰 포인트
int, float, complex, bool, str, bytes, tuple, frozenset, None, range list, dict, set, bytearray, 대부분의 사용자 정의 객체 가변 객체를 기본 인자, 클래스 변수, 모듈 전역 상태로 공유하고 있지 않은가?
튜플은 불변이지만 내용물은 가변일 수 있다
t = ([1, 2], 3)
t[0].append(3)     # OK → ([1, 2, 3], 3)
hash(t)            # TypeError: unhashable type: 'list'

# 유명한 퀴즈
t = (1, [2])
try:
    t[1] += [3]     # TypeError 발생 ...
except TypeError:
    pass
print(t)            # 하지만 (1, [2, 3]) 으로 바뀌어 있다!
왜? t[1] += [3]은 ① t[1].__iadd__([3])로 리스트를 제자리 확장한 뒤 ② 결과를 t[1]에 다시 할당하려다 실패합니다. 1단계는 이미 일어났습니다.
설계 팁 공유되는 설정/상수는 tuple, frozenset, types.MappingProxyType, @dataclass(frozen=True)로 불변으로 만들어 의도치 않은 변경을 막습니다.
from types import MappingProxyType
_DEFAULTS = {"retries": 3, "timeout": 5}
DEFAULTS = MappingProxyType(_DEFAULTS)  # 읽기 전용 뷰
DEFAULTS["retries"] = 10  # TypeError

얕은 복사 vs 깊은 복사

❌ 2차원 리스트를 곱셈으로 만들기
grid = [[0] * 3] * 3      # 같은 내부 리스트 3번 참조
grid[0][0] = 1
print(grid)  # [[1, 0, 0], [1, 0, 0], [1, 0, 0]]
✅ 개선된 코드
grid = [[0] * 3 for _ in range(3)]
grid[0][0] = 1
print(grid)  # [[1, 0, 0], [0, 0, 0], [0, 0, 0]]
복사의 종류
import copy
orig = {"tags": ["a"], "n": 1}

alias   = orig                 # 복사 아님
shallow = orig.copy()          # = dict(orig) = copy.copy(orig)
deep    = copy.deepcopy(orig)

orig["tags"].append("b")
print(shallow["tags"])  # ['a', 'b']  ← 내부는 공유
print(deep["tags"])     # ['a']
  • lst[:], list(lst), lst.copy()는 모두 얕은 복사
  • deepcopy는 비용이 크고 순환 참조/특수 객체(락, 소켓)에서 문제 → 필요한 곳만
  • 사용자 클래스는 __copy__/__deepcopy__로 제어 가능

Truthiness와 None 비교

Falsy 값: None, False, 0, 0.0, 0j, Decimal(0), '', b'', [], (), {}, set(), range(0), 그리고 __bool__이 False 이거나 __len__이 0인 객체.

✅ PEP 8 권장
if not items:            # 빈 시퀀스 검사
    ...
if value is None:        # 싱글톤 비교는 is
    ...
if flag:                 # == True 쓰지 않기
    ...
❌ 0 과 None 을 구분해야 할 때 truthiness 사용
def set_timeout(timeout=None):
    if not timeout:          # timeout=0 도 기본값으로 덮어써짐!
        timeout = 30
    return timeout

set_timeout(0)   # 30  ← 의도는 0 (즉시 타임아웃)
✅ 개선된 코드
def set_timeout(timeout: float | None = None) -> float:
    if timeout is None:
        timeout = 30
    return timeout
리뷰 포인트 x or default 패턴도 같은 문제(0, "", []이 유효한 값일 때). numpy 배열/pandas DataFrame은 if arr:가 ValueError를 냅니다.

스코프: LEGB, global, nonlocal

이름 검색 순서: Local → Enclosing → Global → Built-in.
함수 안 어디서든 이름에 할당이 있으면, 그 이름은 함수 전체에서 로컬로 컴파일 시점에 결정됩니다.

❌ UnboundLocalError
count = 0
def inc():
    count += 1      # count 는 로컬로 간주 → 읽기 전 할당 안 됨
    return count
inc()  # UnboundLocalError
nonlocal 로 클로저 상태 변경
def make_counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc
리뷰 포인트 global은 거의 항상 설계 냄새입니다. 테스트 격리가 깨지고 스레드 안전하지 않습니다. 상태는 객체/인자로 명시적으로 전달하세요.
컴프리헨션은 자체 스코프 (Py3)
x = "outer"
ys = [x for x in range(3)]
print(x)    # 'outer' (Py2 에서는 2 였음)

# 클래스 본문 스코프는 컴프리헨션에서 안 보인다
class C:
    base = 10
    vals = [base + i for i in range(3)]  # NameError: name 'base' is not defined

클래스 본문은 enclosing 스코프가 아니므로 메서드나 컴프리헨션 내부에서 클래스 변수 이름을 바로 참조할 수 없습니다(가장 바깥 iterable인 range(3)만 클래스 스코프에서 평가됨). 3.12의 PEP 709(컴프리헨션 인라이닝) 이후에도 이 규칙은 동일합니다.

데이터 모델: 던더(dunder) 메서드

Python의 문법은 특수 메서드 호출로 번역됩니다. 이를 구현하면 내 객체가 내장 타입처럼 동작합니다.

문법 / 내장 함수호출되는 메서드메모
repr(x), str(x), f"{x}"__repr__, __str__, __format____repr__은 디버깅용, 가능하면 재생성 가능한 형태
len(x), bool(x)__len__, __bool____bool__ 없으면 __len__ 사용
x[k], x[k]=v, k in x__getitem__, __setitem__, __contains____contains__ 없으면 순회로 대체(느림)
for v in x, next(it)__iter__, __next__이터레이터 프로토콜
x == y, hash(x)__eq__, __hash____eq__만 정의하면 __hash__ = None이 됨
x < y, 정렬__lt__ 등functools.total_ordering
x + y, x += y__add__/__radd__, __iadd__지원 불가 타입엔 NotImplemented 반환 (raise 아님!)

from functools import total_ordering

@total_ordering
class Money:
    __slots__ = ("amount", "currency")

    def __init__(self, amount: int, currency: str) -> None:
        self.amount = amount
        self.currency = currency

    def __repr__(self) -> str:
        return f"Money({self.amount!r}, {self.currency!r})"

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, Money):
            return NotImplemented
        return (self.amount, self.currency) == (other.amount, other.currency)

    def __hash__(self) -> int:
        return hash((self.amount, self.currency))

    def __lt__(self, other: "Money") -> bool:
        if not isinstance(other, Money):
            return NotImplemented
        if self.currency != other.currency:
            raise ValueError("currency mismatch")
        return self.amount < other.amount

    def __add__(self, other: "Money") -> "Money":
        if not isinstance(other, Money):
            return NotImplemented
        if self.currency != other.currency:
            raise ValueError("currency mismatch")
        return Money(self.amount + other.amount, self.currency)
  • NotImplemented 반환: 상대 타입이 처리할 기회(__radd__, 반사 비교)를 줍니다. raise NotImplementedError와 혼동하는 것은 흔한 실수.
  • __eq__와 __hash__ 계약: a == b이면 hash(a) == hash(b)이어야 합니다. 해시에 쓰이는 필드는 변경되면 안 됩니다(가변 객체를 dict 키로 쓰면 찾을 수 없게 됨).
  • 돈은 float 금지: 정수(최소 단위)나 decimal.Decimal.
  • __repr__은 로그/디버거에서 보이는 얼굴 — 항상 구현 권장.
  • 사실 이 클래스는 @dataclass(frozen=True, order=True, slots=True)로 대부분 대체 가능 → 리뷰에서 "보일러플레이트를 줄일 수 있다"고 제안.

① 가변 기본 인자 (Mutable Default Argument)

❌ 문제 있는 코드
def add_tag(tag, tags=[]):
    tags.append(tag)
    return tags

기본값은 함수 정의 시점에 한 번 평가되어 함수 객체(add_tag.__defaults__)에 저장됩니다. 모든 호출이 같은 리스트를 공유합니다. dict, set, 사용자 객체도 마찬가지.

✅ 개선된 코드
def add_tag(tag: str, tags: list[str] | None = None) -> list[str]:

        tags = []
    tags.append(tag)
    return tags

② 클로저의 늦은 바인딩 (Late Binding)

❌ 문제 있는 코드

    @staticmethod
    def is_freezing(c: float) -> bool:      # 상태와 무관한 유틸

from collections.abc import Callable

def timed[**P, R](func: Callable[P, R]) -> Callable[P, R]:

인자를 받는 데코레이터 (3단 중첩)
def retry(times: int = 3, exceptions: tuple[type[Exception], ...] = (Exception,),
          backoff: float = 0.5):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions:
                    if attempt == times:
                        raise
                    time.sleep(backoff * 2 ** (attempt - 1))
        return wrapper
    return decorator

@retry(times=5, exceptions=(httpx.TransportError,))
def fetch(url: str) -> bytes: ...

디스크립터 프로토콜

__get__/__set__/__delete__를 가진 객체를 클래스 속성으로 두면 속성 접근을 가로챕니다. property, classmethod, staticmethod, 함수(→ 바운드 메서드), __slots__ 모두 디스크립터입니다.

class Positive:
    def __set_name__(self, owner, name):      # 3.6+: 속성 이름 자동 전달
        self.private = f"_{name}"

    def __get__(self, obj, objtype=None):
        if obj is None:                       # 클래스에서 접근 시
            return self
        return getattr(obj, self.private)

    def __set__(self, obj, value):
        if value <= 0:
            raise ValueError(f"{self.private[1:]} must be > 0")
        setattr(obj, self.private, value)

class Order:
    qty = Positive()
    price = Positive()
    def __init__(self, qty, price):
        self.qty, self.price = qty, price

Order(0, 10)   # ValueError: qty must be > 0

속성 조회 우선순위

  1. 데이터 디스크립터 (__set__ 또는 __delete__ 있음, 예: property) — 클래스(MRO)
  2. 인스턴스 __dict__
  3. 논데이터 디스크립터 (__get__만, 예: 함수, cached_property) 및 일반 클래스 속성
  4. __getattr__ (위에서 모두 실패했을 때만)
그래서 cached_property는 논데이터 디스크립터라, 첫 계산 후 인스턴스 __dict__에 값을 넣으면 다음부턴 디스크립터를 거치지 않습니다 — 빠른 이유.
리뷰 기준 디스크립터는 ORM 필드, 검증 프레임워크처럼 같은 패턴이 많은 클래스에 반복될 때 가치가 있습니다. 한두 개 필드라면 property가 더 읽기 쉽습니다.

        self.log_name = log_name

class Cached(Base):
    def __init__(self, *, cache_size=128, **kw):

        self.cache_size = cache_size
        print("Cached")

class Service(Logged, Cached):

        async with sem:
            async with asyncio.timeout(10):      # 3.11+

class Repo[T]:
    def __init__(self) -> None:
        self._items: dict[str, T] = {}

    def get(self, key: str) -> T | None:
        return self._items.get(key)

def load(path: Path) -> dict[str, str] | None:
    try:
        text = path.read_text(encoding="utf-8")
    except FileNotFoundError:
        return None
    return DEFAULTS | parse(text)

def kind(evt: dict) -> str:
    match evt:
        case {"type": "click", "pos": (x, y)}:

            return f"key {key}"
        case _:

def html(t: Template) -> str:
    out = []
    for part in t:                # 정적 문자열과 Interpolation 이 번갈아 나옴
        if isinstance(part, Interpolation):
            out.append(escape(str(part.value)))
        else:
            out.append(part)
    return "".join(out)

자주 나오는 개념 질문 (1)

Q. 리스트와 튜플의 차이는? 언제 튜플을 쓰나요?

리스트는 가변, 튜플은 불변(내용물이 hashable이면 튜플도 hashable → dict 키/set 원소 가능). 관례적으로 리스트는 같은 종류 원소의 가변 길이 모음, 튜플은 위치마다 의미가 있는 고정 구조(레코드). 튜플은 약간 더 작고 상수 폴딩 등 최적화 대상. 의미 있는 필드명이 필요하면 NamedTuple/dataclass.

Q. GIL이란? 그럼 Python에서 멀티스레드는 무의미한가요?

CPython 인터프리터가 한 번에 한 스레드만 바이트코드를 실행하도록 하는 전역 락. 참조 카운팅을 단순하고 빠르게 유지하기 위한 설계. I/O 대기·C 확장(NumPy, hashlib 등)은 GIL을 풀므로 I/O 바운드 작업엔 스레드가 유효하고, CPU 바운드 순수 Python엔 멀티프로세싱이 필요. 3.13에서 free-threaded 빌드(실험적), 3.14에서 공식 지원 단계로 진입했지만 기본 빌드는 여전히 GIL이 있음. GIL이 있어도 += 같은 복합 연산은 원자적이지 않아 락이 필요.

Q. 이터레이터와 제너레이터의 차이는?

이터레이터는 __iter__와 __next__를 구현한 모든 객체(프로토콜). 제너레이터는 yield를 쓰는 함수(또는 제너레이터 식)로 이터레이터를 쉽게 만드는 방법이며, 실행 상태(프레임)를 보존하고 send/throw/close를 추가로 지원. 둘 다 한 번만 소비 가능.

Q. @staticmethod와 @classmethod의 차이는?

classmethod는 첫 인자로 클래스(cls)를 받아 서브클래스에서 호출 시 서브클래스가 전달됨 → 대체 생성자(from_json)에 적합. staticmethod는 아무것도 바인딩하지 않는 네임스페이스 함수. 모듈 함수로 충분하면 그쪽이 더 단순.

Q. __new__와 __init__의 차이는?

__new__는 인스턴스를 생성하는 정적 메서드(클래스를 받아 새 객체 반환), __init__은 생성된 인스턴스를 초기화(반환값 None). 불변 타입(int, str, tuple) 서브클래싱, 싱글톤, 인스턴스 캐싱에서 __new__를 오버라이드. __new__가 다른 클래스의 인스턴스를 반환하면 __init__은 호출되지 않음.

자주 나오는 개념 질문 (2)

Q. 얕은 복사와 깊은 복사의 차이, deepcopy의 비용은?

얕은 복사는 컨테이너만 새로 만들고 원소는 같은 객체를 참조. 깊은 복사는 재귀적으로 복사하며 memo dict로 순환 참조를 처리. 큰 객체 그래프에서 느리고, 파일·소켓·락처럼 복사 불가능한 객체에서 실패. 불변 데이터 구조를 쓰면 복사 자체가 필요 없어짐.

Q. *args, **kwargs, /, *의 의미는?

def f(a, b, /, c, *, d, **kw): a, b는 위치 전용, c는 위치/키워드 모두, d는 키워드 전용, *args는 나머지 위치 인자 튜플, **kwargs는 나머지 키워드 인자 dict. 위치 전용은 인자 이름을 API에서 숨겨 이름 변경 자유를 주고, 키워드 전용은 호출부 가독성과 인자 순서 변경 자유를 줌.

Q. 데코레이터는 어떻게 동작하나요? functools.wraps는 왜 필요하죠?

@deco는 func = deco(func)의 문법 설탕이며 정의(import) 시점에 실행. 래퍼 함수가 원본을 대체하므로 __name__, __doc__, __module__, __qualname__, __wrapped__가 사라짐 → 디버깅, 로깅, 문서화, inspect.signature, pytest/Flask 같은 이름 기반 프레임워크가 깨짐. wraps가 이를 복사.

Q. Python의 메모리 관리 방식은?

CPython: 참조 카운팅(카운트가 0이 되면 즉시 해제) + 순환 참조를 위한 세대별(3.14부터 증분) 가비지 컬렉터. 작은 객체는 pymalloc 아레나에서 할당. 해제된 메모리가 OS로 바로 반환되지 않을 수 있어 RSS가 줄지 않는 현상이 있음. 약한 참조(weakref)로 캐시·옵저버의 순환/누수 방지.

Q. asyncio와 스레드의 차이, async를 언제 쓰나요?

asyncio는 단일 스레드 이벤트 루프에서 협력적 멀티태스킹(await 지점에서만 전환), 스레드는 OS에 의한 선점형 전환. async는 수천 개의 동시 I/O 연결(웹 서버, 크롤러, 웹소켓)에 효율적이지만 모든 I/O 라이브러리가 async여야 하고 블로킹 호출 하나가 전체를 멈춤. 기존 동기 코드베이스에 소수의 병렬 I/O라면 스레드 풀이 단순.

Q. ==와 is, __eq__와 __hash__의 관계는?

is는 동일 객체(id) 비교, ==는 __eq__로 값 비교. __eq__를 정의하면 __hash__가 자동으로 None이 되어 unhashable. 동등한 객체는 해시가 같아야 하며, 해시에 쓰이는 필드는 불변이어야 함.

from dataclasses import dataclass
from statistics import fmean

@dataclass(frozen=True)
class Student:
    id: int
    name: str
    scores: tuple[float, ...]

    return {
        s.id: bool(s.scores) and fmean(s.scores) >= passing
        for s in students
    }

개선 코드
✅ 개선된 코드
from pathlib import Path

class ConfigError(ValueError):
    pass

def read_config(path: Path) -> dict[str, str]:
    config: dict[str, str] = {}
    with path.open(encoding="utf-8") as f:     # FileNotFoundError 는 전파
        for lineno, raw in enumerate(f, start=1):
            line = raw.strip()
            if not line or line.startswith("#"):
                continue
            key, sep, value = line.partition("=")
            if not sep or not key.strip():
                raise ConfigError(f"{path}:{lineno}: expected key=value")
            config[key.strip()] = value.strip()
    return config

import time
from collections.abc import Iterable, Mapping
from decimal import Decimal
from types import MappingProxyType

class PriceService:
    def __init__(self, db, ttl_s: float = 60.0) -> None:
        self._db = db
        self._ttl_s = ttl_s
        self._cache: dict[int, tuple[Decimal, float]] = {}   # id -> (price, fetched_at)

    def get_prices(self, product_ids: Iterable[int]) -> Mapping[int, Decimal]:
        ids = set(product_ids)
        now = time.monotonic()
        missing = [i for i in ids
                   if i not in self._cache or now - self._cache[i][1] > self._ttl_s]
        if missing:
            rows = self._db.query(
                "SELECT id, price FROM prices WHERE id = ANY(%s)", (missing,))
            for r in rows:
                self._cache[r.id] = (r.price, now)
        return MappingProxyType({i: self._cache[i][0] for i in ids if i in self._cache})

    def cheapest(self, product_ids: Iterable[int]) -> int | None:
        prices = self.get_prices(product_ids)
        return min(prices, key=prices.__getitem__, default=None)

  • [Suggestion] 스레드 안전성: check-then-act 사이에 여러 스레드가 동시에 미스 → 같은 비싼 계산을 중복 수행(cache stampede). 키별 락 또는 single-flight.
  • [Suggestion] L11,14 time.time()은 시스템 시계 변경에 영향 → time.monotonic().
  • [Suggestion] L7 functools.wraps 누락 → 이름·docstring·시그니처 유실. 캐시 무효화 API(cache_clear)도 없음.
  • [Question] 가변 객체 반환 시 공유 문제, 예외는 캐시하지 않는 동작이 의도인지 문서화.
개선 코드
✅ 개선된 코드
import functools, inspect, threading, time
from collections import OrderedDict
from collections.abc import Callable

def ttl_cache[**P, R](ttl_s: float, maxsize: int = 1024):
    def deco(fn: Callable[P, R]) -> Callable[P, R]:
        if inspect.iscoroutinefunction(fn):
            raise TypeError("use an async-aware cache for coroutine functions")
        cache: OrderedDict[object, tuple[R, float]] = OrderedDict()
        lock = threading.Lock()

        @functools.wraps(fn)
        def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
            key = functools._make_key(args, kwargs, typed=False)  # lru_cache 와 동일 규칙
            now = time.monotonic()
            with lock:
                hit = cache.get(key)
                if hit is not None and now - hit[1] < ttl_s:
                    cache.move_to_end(key)
                    return hit[0]
            value = fn(*args, **kwargs)            # 락 밖에서 계산
            with lock:
                cache[key] = (value, time.monotonic())
                cache.move_to_end(key)
                while len(cache) > maxsize:
                    cache.popitem(last=False)      # LRU 축출
            return value

        wrapper.cache_clear = cache.clear           # type: ignore[attr-defined]
        return wrapper
    return deco

functools._make_key는 비공개 API이므로 실제로는 (args, frozenset(kwargs.items()))를 쓰거나 검증된 라이브러리(cachetools.TTLCache)를 권장하는 것이 리뷰의 정답에 더 가깝습니다. 중복 계산(stampede) 방지가 필요하면 키별 락을 추가.

from dataclasses import dataclass
import re

_VERSION_RE = re.compile(r"\d+(\.\d+)*")

@dataclass(frozen=True, order=True, slots=True)
class Version:
    parts: tuple[int, ...]

    @classmethod
    def parse(cls, s: str) -> "Version":
        if not _VERSION_RE.fullmatch(s):
            raise ValueError(f"invalid version string: {s!r}")
        parts = tuple(int(p) for p in s.split("."))
        while len(parts) > 1 and parts[-1] == 0:   # 1.2.0 == 1.2
            parts = parts[:-1]
        return cls(parts)

    def bump(self) -> "Version":
        return Version(self.parts[:-1] + (self.parts[-1] + 1,))

    def __str__(self) -> str:
        return ".".join(map(str, self.parts))

import json, os, re, subprocess, tempfile
from pathlib import Path

NAME_RE = re.compile(r"[A-Za-z0-9_-]{1,64}")
CACHE_DIR = Path(os.environ.get("REPORT_CACHE_DIR", "/var/cache/myapp/reports"))

def run_report(name: str) -> dict:
    if not NAME_RE.fullmatch(name):
        raise ValueError("invalid report name")
    CACHE_DIR.mkdir(mode=0o700, parents=True, exist_ok=True)
    cache_file = CACHE_DIR / f"{name}.json"
    try:
        return json.loads(cache_file.read_text(encoding="utf-8"))
    except FileNotFoundError:
        pass

    proc = subprocess.run(
        ["report-gen", "--name", name],
        capture_output=True, check=True, timeout=60,
    )
    data = parse(proc.stdout)

    # 원자적 쓰기: 같은 디렉터리에 임시 파일 → os.replace
    with tempfile.NamedTemporaryFile("w", dir=CACHE_DIR, delete=False,
                                     encoding="utf-8", suffix=".tmp") as tmp:
        json.dump(data, tmp)
    os.replace(tmp.name, cache_file)
    return data
