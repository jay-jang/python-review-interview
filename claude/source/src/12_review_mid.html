Intermediate 문제 5 — 외부 API 호출

import requests, time, logging def fetch_user(user_id): url = "https://api.example.com/users/" + str(user_id) for i in range(3): try: r = requests.get(url) return r.json() except: logging.error("failed") time.sleep(1)
찾아야 할 이슈
  • [Blocking] L7 timeout 없음 → 서버가 응답하지 않으면 영원히 대기 (워커 고갈).
  • [Blocking] L8 HTTP 상태 검사 없음 → 404/500의 에러 본문을 "사용자 정보"로 반환. 에러 본문이 JSON이 아니면 JSONDecodeError → 재시도.
  • [Blocking] L5-11 3회 실패 후 암묵적 None 반환 → 호출자가 장애를 "없는 사용자"로 착각. 마지막 실패는 예외로 전파.
  • [Blocking] L9 bare except → KeyboardInterrupt까지 잡고, 404 같은 재시도해도 소용없는 오류까지 재시도.
  • [Suggestion] L10 루트 로거 사용, 컨텍스트(user_id, 시도 횟수)와 traceback 없음.
  • [Suggestion] L11 고정 1초 대기 → 지수 백오프 + 지터. 마지막 시도 후 불필요한 sleep.
  • [Suggestion] 매 호출마다 새 연결 → Session/Client 재사용(커넥션 풀). 테스트 위해 클라이언트 주입.
  • [Nit] L4 URL 조립 → f"{BASE}/users/{user_id}", 문자열 ID라면 urllib.parse.quote.
개선 코드
import logging, random, time import httpx log = logging.getLogger(__name__) RETRYABLE_STATUS = {429, 502, 503, 504} class UserNotFound(LookupError): ... def fetch_user(client: httpx.Client, user_id: int, *, attempts: int = 3) -> dict: for attempt in range(1, attempts + 1): try: resp = client.get(f"/users/{user_id}", timeout=5.0) if resp.status_code == 404: raise UserNotFound(user_id) if resp.status_code not in RETRYABLE_STATUS: resp.raise_for_status() return resp.json() log.warning("retryable status %s user_id=%s attempt=%d", resp.status_code, user_id, attempt) except httpx.TransportError: log.warning("transport error user_id=%s attempt=%d", user_id, attempt, exc_info=True) if attempt == attempts: raise if attempt < attempts: time.sleep(0.5 * 2 ** (attempt - 1) + random.uniform(0, 0.1)) raise RuntimeError(f"user {user_id}: retries exhausted")

Intermediate 문제 6 — 가격 서비스와 캐시

from functools import lru_cache class PriceService: def __init__(self, db): self.db = db @lru_cache(maxsize=None) def get_prices(self, product_ids): ids = ",".join(map(str, product_ids)) rows = self.db.query(f"SELECT id, price FROM prices WHERE id IN ({ids})") return {r.id: r.price for r in rows} def cheapest(self, product_ids): prices = self.get_prices(tuple(product_ids)) prices_sorted = sorted(prices.items(), key=lambda x: x[1]) return prices_sorted[0][0]
찾아야 할 이슈
  • [Blocking] L7 메서드에 lru_cache → self가 캐시 키에 포함되어 PriceService 인스턴스와 db가 영원히 해제되지 않음. maxsize=None이라 무한 증가 → 메모리 누수.
  • [Blocking] 가격은 바뀌는 데이터인데 TTL/무효화가 없음 → 오래된 가격으로 판매.
  • [Blocking] L11 캐시된 가변 dict를 그대로 반환 → 호출자가 수정하면 캐시 오염.
  • [Blocking] L10 f-string SQL → 지금은 정수라도 문자열 ID가 들어오면 인젝션. 빈 목록이면 IN () 문법 에러. 파라미터 바인딩.
  • [Blocking] L16 결과가 비면 IndexError. 가격 없는 상품 처리 정책 필요.
  • [Suggestion] L15 최소값에 정렬 O(n log n) → min(prices, key=prices.get) O(n).
  • [Suggestion] L14 tuple(product_ids)는 순서·중복이 다르면 다른 키 → 캐시 효율 저하. frozenset 정규화 또는 상품 단위 캐시.
개선 코드
import time from collections.abc import Iterable, Mapping from decimal import Decimal from types import MappingProxyType class PriceService: def __init__(self, db, ttl_s: float = 60.0) -> None: self._db = db self._ttl_s = ttl_s self._cache: dict[int, tuple[Decimal, float]] = {} # id -> (price, fetched_at) def get_prices(self, product_ids: Iterable[int]) -> Mapping[int, Decimal]: ids = set(product_ids) now = time.monotonic() missing = [i for i in ids if i not in self._cache or now - self._cache[i][1] > self._ttl_s] if missing: rows = self._db.query( "SELECT id, price FROM prices WHERE id = ANY(%s)", (missing,)) for r in rows: self._cache[r.id] = (r.price, now) return MappingProxyType({i: self._cache[i][0] for i in ids if i in self._cache}) def cheapest(self, product_ids: Iterable[int]) -> int | None: prices = self.get_prices(product_ids) return min(prices, key=prices.__getitem__, default=None)

운영에선 캐시 크기 상한(또는 Redis 등 외부 캐시)과 멀티스레드 접근 시 락도 검토.

Intermediate 문제 7 — 계좌 이체

def transfer(db, from_id, to_id, amount): try: from_acc = db.get_account(from_id) to_acc = db.get_account(to_id) if from_acc.balance < amount: raise Exception("insufficient funds") from_acc.balance -= amount db.save(from_acc) to_acc.balance += amount db.save(to_acc) return True except Exception as e: print("transfer error", e) return False
찾아야 할 이슈
  • [Blocking] L7-10 트랜잭션 없음 → from_acc 저장 후 to_acc 저장이 실패하면 돈이 사라짐. 원자적 트랜잭션으로 묶어야 함.
  • [Blocking] L3-7 동시성: 같은 계좌로 동시 이체 시 read-modify-write 경쟁 → 잔액 초과 출금(lost update). SELECT ... FOR UPDATE, 낙관적 락(버전 컬럼), 또는 UPDATE ... SET balance = balance - %s WHERE balance >= %s.
  • [Blocking] amount 검증 없음: 음수 금액이면 역방향 이체(타인 돈 인출), 0, from_id == to_id.
  • [Blocking] L12-14 모든 예외를 삼키고 False → 잔액 부족(비즈니스 오류)과 DB 장애·버그(AttributeError)를 구분 못 함. 로그도 print.
  • [Suggestion] L6 일반 Exception 대신 InsufficientFundsError 같은 도메인 예외.
  • [Suggestion] 금액 타입은 Decimal; 감사(audit) 로그/이체 내역 레코드 필요; 데드락 방지를 위해 계좌 잠금 순서를 ID 순으로 고정.

Intermediate 문제 8 — 이벤트 로그 집계

import csv, datetime def load_events(path): events = [] with open(path) as f: for row in csv.DictReader(f): row['ts'] = datetime.datetime.strptime(row['ts'], '%Y-%m-%d %H:%M:%S') events.append(row) return events def daily_counts(path): events = load_events(path) counts = {} for e in events: day = e['ts'].date() if day not in counts: counts[day] = 0 counts[day] += 1 today = datetime.datetime.now().date() return counts, counts.get(today, 0)

로그 파일은 하루 수 GB, 타임스탬프는 UTC로 기록됨.

찾아야 할 이슈
  • [Blocking] L19 로그는 UTC인데 now()는 서버 로컬 시간 → 한국(UTC+9) 서버에선 0~9시 사이 "오늘" 집계가 틀림. 날짜 경계도 UTC 기준인지 KST 기준인지 요구사항 확인.
  • [Blocking] L4-9 수 GB 파일을 전부 리스트로 로드 → 메모리 폭발. 집계만 필요하므로 스트리밍.
  • [Suggestion] L5 encoding, newline="" 누락 (csv 모듈 권장 사항: 필드 안 개행 처리).
  • [Suggestion] L7 잘못된 행 하나에 전체 작업 실패 → 정책 결정(스킵 + 카운트 로깅 또는 실패).
  • [Suggestion] L19-20 현재 시각을 함수 안에서 호출 → 테스트 비결정적. 반환값이 "전체 집계 + 오늘 값" 두 책임 → 분리.
  • [Nit] L13-18 Counter로 대체. datetime.fromisoformat이 strptime보다 빠름.
개선 코드
import csv from collections import Counter from collections.abc import Iterable, Iterator from datetime import date, datetime, timezone, tzinfo from pathlib import Path from zoneinfo import ZoneInfo def iter_timestamps(path: Path) -> Iterator[datetime]: with path.open(encoding="utf-8", newline="") as f: for row in csv.DictReader(f): yield datetime.fromisoformat(row["ts"]).replace(tzinfo=timezone.utc) def daily_counts(timestamps: Iterable[datetime], tz: tzinfo = timezone.utc) -> Counter[date]: return Counter(ts.astimezone(tz).date() for ts in timestamps) # 호출부 counts = daily_counts(iter_timestamps(path), tz=ZoneInfo("Asia/Seoul")) today = datetime.now(ZoneInfo("Asia/Seoul")).date() print(counts[today])
