PART 10 · B

코드 리뷰 실전 문제

각 문제는 "PR로 올라온 코드"라고 가정합니다. 다음 순서로 답해 보세요.

  1. 이 코드의 의도를 한 문장으로 요약
  2. 이슈를 [Blocking] / [Suggestion] / [Nit]로 분류해 줄 번호와 함께 나열
  3. 가장 중요한 이슈 1~2개에 대해 리뷰 코멘트를 실제 문장으로 작성
  4. 개선된 코드 제시

Junior 문제 1 — 성적 처리

def average_scores(students, passing=60, result={}): for i in range(len(students)): s = students[i] total = 0 for score in s['scores']: total = total + score avg = total / len(s['scores']) if avg >= passing: result[s['name']] = 'PASS' else: result[s['name']] = 'FAIL' return result
찾아야 할 이슈
  • [Blocking] L1 가변 기본 인자 result={}: 호출 간 결과가 누적됨. 두 번째 반 성적을 처리하면 첫 번째 반 학생까지 섞여 반환.
  • [Blocking] L7 scores가 빈 리스트면 ZeroDivisionError. 정책(제외? FAIL? 에러?) 결정 필요.
  • [Suggestion] L9 이름이 키 → 동명이인이면 덮어씀. 학생 ID를 키로.
  • [Suggestion] 'PASS'/'FAIL' 매직 문자열 → bool 또는 Enum.
  • [Nit] L2-6 range(len()), 수동 합계 → for s in students, sum(), statistics.fmean.
  • [Nit] 타입 힌트, docstring 부재. dict 대신 dataclass 고려.
개선 코드
from collections.abc import Iterable from dataclasses import dataclass from statistics import fmean @dataclass(frozen=True) class Student: id: int name: str scores: tuple[float, ...] def pass_status(students: Iterable[Student], passing: float = 60) -> dict[int, bool]: """Return {student_id: passed}. Students without scores are treated as failed.""" return { s.id: bool(s.scores) and fmean(s.scores) >= passing for s in students }

Junior 문제 2 — 설정 파일 읽기

import os def read_config(path): if os.path.exists(path): f = open(path) lines = f.readlines() config = {} for line in lines: if line.startswith('#') or line == '\n': continue key, value = line.split('=') config[key] = value return config else: print("config not found") # db settings host = localhost url=postgres://u:p@h/db?sslmode=require
찾아야 할 이슈
  • [Blocking] L11 값에 =가 있으면(url=...?sslmode=require) ValueError: too many values to unpack. partition('=') 또는 split('=', 1). = 없는 줄도 에러.
  • [Blocking] L12 공백·개행 미제거: 키가 'host ', 값이 ' localhost\n'. 마지막 줄 개행 유무에 따라 결과가 달라짐.
  • [Blocking] L5 파일을 닫지 않음, 인코딩 미지정 → with open(..., encoding="utf-8").
  • [Suggestion] L4/L15 파일 없음 시 print 후 암묵적 None 반환 → 호출자가 config['host']에서 TypeError. 예외를 전파하거나 명시적 기본값. exists 검사는 TOCTOU.
  • [Suggestion] L9 공백만 있는 줄, 들여쓴 주석( # x), Windows 개행(\r\n) 미처리.
  • [Suggestion] 바퀴 재발명: TOML(tomllib), configparser, 환경변수 사용 검토.
개선 코드
from pathlib import Path class ConfigError(ValueError): pass def read_config(path: Path) -> dict[str, str]: config: dict[str, str] = {} with path.open(encoding="utf-8") as f: # FileNotFoundError 는 전파 for lineno, raw in enumerate(f, start=1): line = raw.strip() if not line or line.startswith("#"): continue key, sep, value = line.partition("=") if not sep or not key.strip(): raise ConfigError(f"{path}:{lineno}: expected key=value") config[key.strip()] = value.strip() return config

Junior 문제 3 — 사용자 정리

def clean_users(users): seen = [] for u in users: if u['active'] == False: users.remove(u) elif u['email'] in seen: users.remove(u) else: seen.append(u['email']) return users users = [ {"email": "a@x.com", "active": False}, {"email": "b@x.com", "active": False}, {"email": "A@x.com", "active": True}, {"email": "a@x.com", "active": True}, ]
찾아야 할 이슈
  • [Blocking] L3-7 순회 중 리스트에서 remove → 다음 원소를 건너뜀. 위 입력에서 b@x.com(비활성)이 검사되지 않고 남습니다.
  • [Blocking] 입력 리스트를 제자리 변경하면서 반환까지 함 → 호출자의 원본 데이터가 몰래 바뀜. 새 리스트 반환이 안전.
  • [Blocking] remove(u)는 ==로 첫 번째 일치 원소를 지움 → 같은 내용의 dict가 앞에 있으면 엉뚱한 원소 삭제.
  • [Suggestion] L6 seen이 리스트 → O(n²). set 사용.
  • [Suggestion] 이메일 대소문자/공백 정규화 누락 (A@x.com vs a@x.com) — 도메인 정책 확인 질문.
  • [Nit] L4 == False → if not u['active'].
개선 코드
def clean_users(users: Iterable[dict]) -> list[dict]: """Return active users, keeping the first occurrence of each email.""" seen: set[str] = set() result: list[dict] = [] for u in users: if not u["active"]: continue key = u["email"].strip().casefold() if key in seen: continue seen.add(key) result.append(u) return result

Junior 문제 4 — 장바구니

class ShoppingCart: items = [] discount = 0 def add(self, name, price, qty=1): self.items.append({'name': name, 'price': price, 'qty': qty}) def total(self): total = 0 for item in self.items: total += item['price'] * item['qty'] return total - total * self.discount / 100 def apply_coupon(self, code): if code == 'SALE10': self.discount = 10 if code == 'SALE20': self.discount = 20 else: self.discount = 0
찾아야 할 이슈
  • [Blocking] L2 items가 클래스 변수 → 모든 사용자의 장바구니가 공유됨 (웹 서버에서 개인정보·결제 사고).
  • [Blocking] L15-20 if/if/else: SALE10을 적용하면 두 번째 if가 거짓이라 else로 가서 할인이 0으로 초기화. elif 필요.
  • [Blocking] L12 금액에 float 연산 → Decimal/정수 센트, 반올림 정책 명시.
  • [Suggestion] L5 price, qty 검증 없음 (음수 수량으로 총액 조작 가능).
  • [Suggestion] 잘못된 쿠폰 코드가 조용히 기존 할인을 지움 → 예외 또는 결과 반환. 쿠폰 표는 상수 매핑으로.
  • [Nit] dict 대신 LineItem dataclass, 타입 힌트.
개선 코드
from dataclasses import dataclass, field from decimal import Decimal, ROUND_HALF_UP COUPONS: dict[str, Decimal] = {"SALE10": Decimal("10"), "SALE20": Decimal("20")} @dataclass(frozen=True) class LineItem: name: str unit_price: Decimal qty: int = 1 def __post_init__(self) -> None: if self.unit_price < 0 or self.qty <= 0: raise ValueError(f"invalid line item: {self}") @dataclass class ShoppingCart: items: list[LineItem] = field(default_factory=list) discount_pct: Decimal = Decimal("0") def add(self, item: LineItem) -> None: self.items.append(item) def apply_coupon(self, code: str) -> None: try: self.discount_pct = COUPONS[code] except KeyError: raise ValueError(f"unknown coupon: {code!r}") from None def total(self) -> Decimal: subtotal = sum((i.unit_price * i.qty for i in self.items), Decimal("0")) total = subtotal * (100 - self.discount_pct) / 100 return total.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
