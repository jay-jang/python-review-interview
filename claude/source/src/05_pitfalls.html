인터뷰용 코드에는 이 중 2~4개가 거의 반드시 숨어 있습니다. 패턴으로 외워 두면 몇 초 만에 발견할 수 있습니다.

① 가변 기본 인자 (Mutable Default Argument)

def add_tag(tag, tags=[]): tags.append(tag) return tags print(add_tag("a")) # ['a'] print(add_tag("b")) # ['a', 'b'] ← ?!

기본값은 함수 정의 시점에 한 번 평가되어 함수 객체(add_tag.__defaults__)에 저장됩니다. 모든 호출이 같은 리스트를 공유합니다. dict, set, 사용자 객체도 마찬가지.

def add_tag(tag: str, tags: list[str] | None = None) -> list[str]: if tags is None: tags = [] tags.append(tag) return tags
같은 원리의 변형 def log(msg, when=datetime.now()): # 정의 시점 시각으로 고정! ... def handler(req, cache={}): # 의도된 메모이제이션이라도 ... # 숨은 전역 상태 → lru_cache 사용

Ruff/flake8-bugbear 규칙 B006, B008이 자동으로 잡습니다.

② 클로저의 늦은 바인딩 (Late Binding)

funcs = [lambda: i for i in range(3)] print([f() for f in funcs]) # [2, 2, 2] buttons = [] for name in ["ok", "cancel"]: buttons.append(Button(on_click=lambda: handle(name))) # 두 버튼 모두 handle("cancel")

클로저는 값이 아니라 변수(셀)를 캡처합니다. 함수가 호출될 때 변수를 조회하므로 루프의 마지막 값이 보입니다.

# 1) 기본 인자로 현재 값 고정 (관용구) funcs = [lambda i=i: i for i in range(3)] # 2) functools.partial from functools import partial buttons = [Button(on_click=partial(handle, name)) for name in names] # 3) 팩토리 함수 def make_handler(name): return lambda: handle(name)
비동기 코드에서도 루프 안에서 콜백/태스크를 만들 때 동일하게 발생합니다 (loop.call_later(1, lambda: print(i))). Ruff B023.

③ 순회 중 컬렉션 수정

nums = [1, 2, 2, 3, 4] for n in nums: if n % 2 == 0: nums.remove(n) print(nums) # [1, 2, 3] ← 2 하나가 남음 (인덱스 건너뜀) d = {"a": 1, "b": 2} for k in d: if d[k] == 1: del d[k] # RuntimeError: dictionary changed size during iteration
nums = [n for n in nums if n % 2 != 0] # 새 리스트 nums[:] = [n for n in nums if n % 2 != 0] # 같은 객체 유지가 필요하면 d = {k: v for k, v in d.items() if v != 1} for k in list(d): # 키 스냅샷 후 삭제 if d[k] == 1: del d[k]
리뷰 포인트 리스트에선 에러 없이 틀린 결과가 나와서 더 위험합니다. 인덱스로 역순 순회(for i in reversed(range(len(xs))))도 가능하지만 컴프리헨션이 가장 명확합니다.
