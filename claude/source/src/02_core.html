PART 2

Python의 핵심 모델

대부분의 "이상한 버그"는 이름(name)과 객체(object)의 관계, 가변성(mutability), 스코프를 잘못 이해한 데서 나옵니다. 리뷰어는 이 모델로 코드를 읽어야 합니다.

모든 것은 객체, 변수는 "이름표"

  • 변수는 값을 담는 상자가 아니라 객체에 붙은 이름(참조)입니다.
  • =는 복사가 아니라 바인딩입니다. b = a는 같은 객체에 이름을 하나 더 붙일 뿐.
  • 모든 객체는 정체성(id), 타입, 값을 가집니다. is는 정체성, ==는 값(__eq__) 비교.
  • 함수 인자 전달은 "call by sharing(객체 참조 전달)": 함수 안에서 객체를 변경하면 호출자에게 보이고, 이름을 재바인딩하면 보이지 않습니다.
a = [1, 2, 3] b = a # 같은 리스트 객체 b.append(4) print(a) # [1, 2, 3, 4] print(a is b) # True
def mutate(xs): xs.append(99) # 호출자의 객체가 바뀜 def rebind(xs): xs = [0] # 로컬 이름만 바뀜 data = [1] mutate(data); print(data) # [1, 99] rebind(data); print(data) # [1, 99] t = [1] u = t t += [2] # list.__iadd__ → 제자리 변경 print(u) # [1, 2] s = (1,) v = s s += (2,) # 튜플은 새 객체 생성 print(v) # (1,)

가변(Mutable) vs 불변(Immutable)

불변 (hashable 가능)가변 (unhashable)리뷰 포인트
int, float, complex, bool, str, bytes, tuple, frozenset, None, range list, dict, set, bytearray, 대부분의 사용자 정의 객체 가변 객체를 기본 인자, 클래스 변수, 모듈 전역 상태로 공유하고 있지 않은가?
t = ([1, 2], 3) t[0].append(3) # OK → ([1, 2, 3], 3) hash(t) # TypeError: unhashable type: 'list' # 유명한 퀴즈 t = (1, [2]) try: t[1] += [3] # TypeError 발생 ... except TypeError: pass print(t) # 하지만 (1, [2, 3]) 으로 바뀌어 있다!
왜? t[1] += [3]은 ① t[1].__iadd__([3])로 리스트를 제자리 확장한 뒤 ② 결과를 t[1]에 다시 할당하려다 실패합니다. 1단계는 이미 일어났습니다.
설계 팁 공유되는 설정/상수는 tuple, frozenset, types.MappingProxyType, @dataclass(frozen=True)로 불변으로 만들어 의도치 않은 변경을 막습니다.
from types import MappingProxyType _DEFAULTS = {"retries": 3, "timeout": 5} DEFAULTS = MappingProxyType(_DEFAULTS) # 읽기 전용 뷰 DEFAULTS["retries"] = 10 # TypeError

얕은 복사 vs 깊은 복사

grid = [[0] * 3] * 3 # 같은 내부 리스트 3번 참조 grid[0][0] = 1 print(grid) # [[1, 0, 0], [1, 0, 0], [1, 0, 0]] grid = [[0] * 3 for _ in range(3)] grid[0][0] = 1 print(grid) # [[1, 0, 0], [0, 0, 0], [0, 0, 0]]
import copy orig = {"tags": ["a"], "n": 1} alias = orig # 복사 아님 shallow = orig.copy() # = dict(orig) = copy.copy(orig) deep = copy.deepcopy(orig) orig["tags"].append("b") print(shallow["tags"]) # ['a', 'b'] ← 내부는 공유 print(deep["tags"]) # ['a']
  • lst[:], list(lst), lst.copy()는 모두 얕은 복사
  • deepcopy는 비용이 크고 순환 참조/특수 객체(락, 소켓)에서 문제 → 필요한 곳만
  • 사용자 클래스는 __copy__/__deepcopy__로 제어 가능

Truthiness와 None 비교

Falsy 값: None, False, 0, 0.0, 0j, Decimal(0), '', b'', [], (), {}, set(), range(0), 그리고 __bool__이 False 이거나 __len__이 0인 객체.

if not items: # 빈 시퀀스 검사 ... if value is None: # 싱글톤 비교는 is ... if flag: # == True 쓰지 않기 ...
def set_timeout(timeout=None): if not timeout: # timeout=0 도 기본값으로 덮어써짐! timeout = 30 return timeout set_timeout(0) # 30 ← 의도는 0 (즉시 타임아웃) def set_timeout(timeout: float | None = None) -> float: if timeout is None: timeout = 30 return timeout
리뷰 포인트 x or default 패턴도 같은 문제(0, "", []이 유효한 값일 때). numpy 배열/pandas DataFrame은 if arr:가 ValueError를 냅니다.

스코프: LEGB, global, nonlocal

이름 검색 순서: Local → Enclosing → Global → Built-in.
함수 안 어디서든 이름에 할당이 있으면, 그 이름은 함수 전체에서 로컬로 컴파일 시점에 결정됩니다.

count = 0 def inc(): count += 1 # count 는 로컬로 간주 → 읽기 전 할당 안 됨 return count inc() # UnboundLocalError def make_counter(): count = 0 def inc(): nonlocal count count += 1 return count return inc
리뷰 포인트 global은 거의 항상 설계 냄새입니다. 테스트 격리가 깨지고 스레드 안전하지 않습니다. 상태는 객체/인자로 명시적으로 전달하세요.
x = "outer" ys = [x for x in range(3)] print(x) # 'outer' (Py2 에서는 2 였음) # 클래스 본문 스코프는 컴프리헨션에서 안 보인다 class C: base = 10 vals = [base + i for i in range(3)] # NameError: name 'base' is not defined

클래스 본문은 enclosing 스코프가 아니므로 메서드나 컴프리헨션 내부에서 클래스 변수 이름을 바로 참조할 수 없습니다(가장 바깥 iterable인 range(3)만 클래스 스코프에서 평가됨). 3.12의 PEP 709(컴프리헨션 인라이닝) 이후에도 이 규칙은 동일합니다.

Python의 문법은 특수 메서드 호출로 번역됩니다. 이를 구현하면 내 객체가 내장 타입처럼 동작합니다.

데이터 모델 구현 예시와 리뷰 포인트

from functools import total_ordering @total_ordering class Money: __slots__ = ("amount", "currency") def __init__(self, amount: int, currency: str) -> None: self.amount = amount self.currency = currency def __repr__(self) -> str: return f"Money({self.amount!r}, {self.currency!r})" def __eq__(self, other: object) -> bool: if not isinstance(other, Money): return NotImplemented return (self.amount, self.currency) == (other.amount, other.currency) def __hash__(self) -> int: return hash((self.amount, self.currency)) def __lt__(self, other: "Money") -> bool: if not isinstance(other, Money): return NotImplemented if self.currency != other.currency: raise ValueError("currency mismatch") return self.amount < other.amount def __add__(self, other: "Money") -> "Money": if not isinstance(other, Money): return NotImplemented if self.currency != other.currency: raise ValueError("currency mismatch") return Money(self.amount + other.amount, self.currency)
  • NotImplemented 반환: 상대 타입이 처리할 기회(__radd__, 반사 비교)를 줍니다. raise NotImplementedError와 혼동하는 것은 흔한 실수.
  • __eq__와 __hash__ 계약: a == b이면 hash(a) == hash(b)이어야 합니다. 해시에 쓰이는 필드는 변경되면 안 됩니다(가변 객체를 dict 키로 쓰면 찾을 수 없게 됨).
  • 돈은 float 금지: 정수(최소 단위)나 decimal.Decimal.
  • __repr__은 로그/디버거에서 보이는 얼굴 — 항상 구현 권장.
  • 사실 이 클래스는 @dataclass(frozen=True, order=True, slots=True)로 대부분 대체 가능 → 리뷰에서 "보일러플레이트를 줄일 수 있다"고 제안.
class Key: def __init__(self, v): self.v = v def __eq__(self, o): return self.v == o.v def __hash__(self): return hash(self.v) k = Key(1); d = {k: "x"} k.v = 2 print(d.get(Key(1)), d.get(Key(2))) # None None ← 영원히 못 찾음

이터러블 vs 이터레이터 (일회성 소비)

  • Iterable: __iter__로 새 이터레이터를 돌려주는 객체 (list, dict, str, 파일 …)
  • Iterator: __next__로 값을 하나씩 내고 끝나면 StopIteration. __iter__는 자기 자신 반환 → 한 번만 순회 가능
  • 제너레이터, map, filter, zip, enumerate, 파일 객체, csv.reader는 모두 이터레이터
def load(path): return (line.strip() for line in open(path)) rows = load("data.txt") total = sum(1 for _ in rows) first = next(iter(rows), None) # 항상 None!
class Lines: def __init__(self, path: str) -> None: self.path = path def __iter__(self): with open(self.path, encoding="utf-8") as f: for line in f: yield line.rstrip("\n") lines = Lines("data.txt") n = sum(1 for _ in lines) # 순회할 때마다 새로 연다 first = next(iter(lines), None)
리뷰 포인트 함수가 "iterable"을 받는다고 문서화해 놓고 내부에서 두 번 순회하면, 제너레이터를 넘긴 호출자는 조용히 잘못된 결과를 받습니다. 두 번 필요하면 list()로 고정하거나 Sequence 타입을 요구하세요.

is 와 == 그리고 CPython 구현 디테일

>>> a = 256; b = 256 >>> a is b True >>> a = 257; b = 257 # 같은 줄/코드 객체 안에서는 상수 공유로 True 일 수도 >>> int("257") is int("257") False >>> "hello" is "hello" # SyntaxWarning: "is" with a literal True
  • CPython은 -5~256 정수와 일부 문자열을 캐싱/인턴(intern)합니다. 이는 구현 세부사항입니다.
  • is는 None, True/False(굳이 비교할 때), 센티널 객체, Ellipsis 비교에만 사용.
_MISSING = object() def get(d: dict, key, default=_MISSING): try: return d[key] except KeyError: if default is _MISSING: raise return default
float 비교 0.1 + 0.2 == 0.3은 False. math.isclose(a, b, rel_tol=1e-9) 사용. float('nan') == float('nan')도 False이며, nan in [nan]은 동일 객체라 True(컨테이너는 is를 먼저 검사).
