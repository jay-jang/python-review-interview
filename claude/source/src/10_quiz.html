PART 10

실전 문제

A. 출력 예측 퀴즈 16문항 — 언어 모델 이해도를 빠르게 점검합니다.
B. 코드 리뷰 문제 12문항 — Junior 4 · Intermediate 4 · Expert 4. 실제 인터뷰처럼 10~15분 타이머를 켜고, 이슈를 심각도별로 정리한 뒤 정답을 펼쳐 보세요.

모든 출력은 CPython 3.11~3.14에서 실행해 확인한 결과입니다. 정답은 ▶ 를 클릭하면 펼쳐집니다.

출력 예측 Q1 ~ Q4

def f(x, acc=[]): acc.append(x) return acc print(f(1), f(2))
정답

[1, 2] [1, 2] — 기본값 리스트가 공유될 뿐 아니라, 두 호출이 같은 객체를 반환하므로 print 시점엔 둘 다 [1, 2]입니다. (인자는 print 호출 전에 모두 평가됨)

ms = [lambda x: i * x for i in range(4)] print([m(2) for m in ms])
정답

[6, 6, 6, 6] — 늦은 바인딩. 모든 람다가 같은 변수 i를 참조하고, 호출 시점의 값은 3. 수정: lambda x, i=i: i * x.

a = [1, 2, 3]; b = a a = a + [4] print(b) c = [1, 2, 3]; d = c c += [4] print(d)
정답

[1, 2, 3] 그리고 [1, 2, 3, 4] — a + [4]는 새 리스트를 만들어 a를 재바인딩, c += [4]는 __iadd__로 제자리 확장(= extend).

print(round(2.5), round(-0.5), int(-2.7), -7 // 2)
정답

2 0 -2 -4 — round는 짝수 쪽으로(은행가 반올림), int()는 0 방향 절삭, //는 내림(음의 무한대 방향).

출력 예측 Q5 ~ Q8

print({True: "a", 1: "b", 1.0: "c"})
정답

{True: 'c'} — True == 1 == 1.0이고 해시도 같아 같은 키. 키는 처음 삽입된 객체(True)가 유지되고 값은 마지막 것으로 덮어씀.

def g(): try: return 1 finally: return 2 print(g())
정답

2 — finally의 return이 이전 return을 덮어씁니다. 예외였다면 예외도 삼킵니다. 3.14부터 SyntaxWarning (PEP 765). 리뷰에서 반드시 지적.

x = [[]] * 2 x[0].append(1) print(x)
정답

[[1], [1]] — 시퀀스 곱셈은 참조를 복제. [[] for _ in range(2)] 사용.

gen = (i for i in range(3)) print(list(gen), list(gen), sum(gen))
정답

[0, 1, 2] [] 0 — 제너레이터는 일회성. 이미 소진된 이터레이터는 에러 없이 빈 결과.

출력 예측 Q9 ~ Q12

class A: x = [] a, b = A(), A() a.x.append(1) b.x = [2] print(A.x, a.x, b.x)
정답

[1] [1] [2] — a.x.append는 클래스 속성 리스트를 변경(공유). b.x = [2]는 b의 인스턴스 속성을 새로 만들어 클래스 속성을 가림.

print(False == False in [False])
정답

True — ==와 in은 같은 우선순위의 비교 연산자라 체이닝됩니다: (False == False) and (False in [False]). (False == False) in [False]로 읽으면 False가 될 것 같지만 아닙니다.

x = 10 def h(): print(x) x = 20 h()
정답

UnboundLocalError: cannot access local variable 'x' where it is not associated with a value — 함수 내 어딘가에 할당이 있으므로 x는 컴파일 시점에 로컬로 결정됨. print(x) 시점엔 아직 할당 전.

d1 = {"x": 1, "y": 2} d2 = d1 | {"x": 3} print(d2, d1)
정답

{'x': 3, 'y': 2} {'x': 1, 'y': 2} — |는 새 dict를 반환(오른쪽 우선, 순서는 왼쪽 키 순서 유지). 제자리 변경은 |= 또는 update.

출력 예측 Q13 ~ Q16

class A: def who(self): return "A" class B(A): def who(self): return "B" + super().who() class C(A): def who(self): return "C" + super().who() class D(B, C): def who(self): return "D" + super().who() print(D().who())
정답

DBCA — MRO는 D → B → C → A → object. B의 super()는 A가 아니라 MRO상 다음인 C.

class P: def __eq__(self, other): return True print({P()})
정답

TypeError: unhashable type: 'P' — __eq__만 정의하면 __hash__가 None으로 설정됩니다.

print(sorted([3, 1, 2]).reverse())
정답

None — list.reverse()는 제자리 변경 후 None 반환. sorted(xs, reverse=True)를 쓰세요.

arr = [1, 8, 15] g = (x for x in arr if arr.count(x) > 0) arr = [2, 8, 22] print(list(g))
정답

[8] — 제너레이터 식에서 가장 바깥 iterable(arr)만 즉시 평가되어 원래 리스트 [1, 8, 15]를 순회하고, if 조건의 arr는 실행 시점에 조회되어 새 리스트 [2, 8, 22]를 봅니다. 두 리스트에 모두 있는 8만 남음.
