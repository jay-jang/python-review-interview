# Python 코드 리뷰 인터뷰 · Codex

123페이지 분량의 독립 실행 HTML 프레젠테이션입니다. Junior, Intermediate, Expert 단계별로 문법·스타일·흔한 실수·설계·테스트·고급 기능을 설명합니다. 실전 리뷰 문제 24개에는 해설, 수정 코드, 회귀 테스트, 채점 기준과 후속 질문이 있습니다.

[GitHub Pages에서 보기](https://jay-jang.github.io/python-review-interview/codex/) 또는 `index.html`을 다운로드해 브라우저에서 열면 됩니다. 한글·코드 글꼴과 모든 화면 자원이 파일 안에 포함되어 있어 열람에는 인터넷이나 설치가 필요하지 않습니다. 공식 문서 링크를 방문할 때는 인터넷이 필요합니다.

## 주요 기능

- 발표 모드와 전체 내용을 펼치는 학습 모드
- 목차 검색, 난이도 필터, 페이지 직접 이동
- 상세 설명과 문제 해설 펼치기
- 코드 복사, 글자 크기 조절, 전체 화면
- 문제별 답안의 브라우저 로컬 저장 및 텍스트 내보내기
- 인쇄 / PDF 저장 및 문제 해설 포함 여부 선택
- 표준 라이브러리만 사용하는 실행 예제 다운로드

## 조작 방법

- `←` / `→` / `Space`: 슬라이드 이동
- `Home` / `End`: 처음·끝 이동
- `T`: 목차·검색
- `N`: 상세 해설
- `A`: 문제 해설
- `F`: 전체 화면

답안은 현재 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제나 파일·주소 변경에 대비해 답안 내보내기를 사용하세요.

## 실행 예제

브라우저는 Python 코드를 실행하지 않습니다. 별도 실습은 Python 3.11 이상에서 다음 명령으로 진행합니다.

```bash
python3 codex/python_review_lab.py
```

외부 패키지와 네트워크가 필요하지 않습니다. 상태 공유, generator, 캐시, SQL 바인딩, TaskGroup, 취소, bounded queue 등을 다루는 27개 테스트가 포함되어 있습니다.

본문의 기본 예제는 Python 3.11+ 기준입니다. 3.12+ 문법과 Python 3.14 전용 기능은 별도로 표시했습니다. 일부 설명용 조각은 본문에 정의한 외부 API·문맥을 전제로 하므로 독립 실행 예제와 구분해서 사용하세요.
