Anti-Pattern 01 JUNIOR F4

가변 기본 인자 (Mutable Default Arguments)

⚙️ CPython 내부 메커니즘 분석

파이썬에서 함수 정의문(def)은 실행 구문입니다. 함수 기본 인자는 함수를 호출할 때가 아니라, 함수 정의 시점에 단 1회 평가(default argument evaluated at def time)되어 함수 객체의 __defaults__ 튜플에 저장됩니다. 따라서 []나 {} 같은 가변 객체를 기본값으로 지정하면, 함수가 여러 번 호출되는 동안 동일한 힙 메모리 객체의 참조가 모든 호출 간에 공유되어 이전 호출의 상태가 누적되는 치명적 부수효과가 발생합니다.

가변 기본 인자 비교

❌ Before (Review 대상 / Bad)

# [BAD] 함수 정의 시점에 리스트가 생성되어 모든 호출 간에 공유됨
def add_user(user_id: int, tags: list = []):
    tags.append(f"user_{user_id}")
    return {"id": user_id, "tags": tags}

Anti-Pattern 02 INTERMEDIATE F5

많은 개발자가 "GIL(글로벌 인터프리터 락)이 있으므로 스레드 안전하다"고 오해하거나, CPU 연산에 threading을 투입합니다. GIL은 CPython 내부 C 구조체만 보호할 뿐, 여러 바이트코드(LOAD_FAST → BINARY_ADD → STORE_FAST)로 분해되는 비원자적 연산(+=)의 데이터 레이스를 보호하지 않습니다. 또한 CPU 연산에 멀티스레드를 사용하면 GIL 경합과 OS 컨텍스트 스위칭 오버헤드로 인해 단일 스레드보다 실행 속도가 오히려 현저히 느려집니다.

CPU 바운드 동시성 모델 비교

❌ Before (Review 대상 / Bad)

import threading

    return sum(i * i for i in range(n))

# 멀티스레드로 CPU 연산 실행 시 단일 스레드보다 훨씬 느림!

for t in threads: t.start()
for t in threads: t.join()

        results = [f.result() for f in futures]
    return results

Anti-Pattern 10 INTERMEDIATE F13

동적 SQL & 쉘 인젝션 취약점 (Injection Flaws)

Anti-Pattern 12 EXPERT F15

순환 참조와 __del__의 함정 (Circular References)

⚙️ CPython 내부 메커니즘 분석

CPython의 기본 메모리 관리는 참조 카운팅(Reference Counting)에 의존합니다. 두 객체가 서로를 강참조(Strong Reference)하면 참조 카운트가 결코 0이 되지 않아 순환 가비지 컬렉터(Cyclic GC)가 개입해야 합니다. 하지만 만약 두 객체 중 하나라도 __del__ 파이널라이저를 정의하고 있으면, CPython은 어떤 객체의 소멸자를 먼저 호출해야 안전한지 알 수 없어 수거를 포기하고 순환 가비지가 메모리에 영구 잔류하여 심각한 메모리 누수를 유발합니다 (Python 3.4 이전 uncollectable, 3.4+에서도 호출 순서 비결정론적).

Modern Feature Python 3.10+ F16

구조적 패턴 매칭 (Structural Pattern Matching)

Python 3.10에 도입된 구조적 패턴 매칭(Pattern Matching)은 단순한 값 비교를 넘어, 시퀀스 및 딕셔너리의 구조를 해체(Destructuring)하고 가드(Guard) 조건식과 결합하여 안전하게 매칭합니다.

match / case 문법과 가드 조건(if)

# Python 3.10+ 구조적 패턴 매칭 실무 예시
def process_command(command: list[str] | dict):
    match command:
        case ["quit"]:
            return "Shutdown service"
            
        case ["move", int(x), int(y)] if x > 0 and y > 0:
            return f"Moving to positive coords ({x}, {y})"
            
        case {"action": "alert", "severity": ("high" | "critical")}:
            return "Trigger urgent notification"
            
        case _:
            return "Default fallback handler"

💡 코드 리뷰어 관점 & 가드레일

  • 가드 조건 (Guard): case ... if condition:으로 구조 매칭과 비즈니스 조건 검증을 1단계로 결합.
  • 가독성 개선: 복잡하고 중첩된 isinstance()와 if-elif-else 체인을 획기적으로 정리.
  • 와일드카드 _: 처리되지 않은 모든 예외 입력에 대해 안전한 기본값 반환.
Modern Feature Python 3.11+ F17

Exception Groups & except* (다중 예외 처리)

비동기 태스크나 멀티스레드 배치 작업에서 여러 작업이 동시에 실패할 때 발생하는 동시 다중 예외(concurrent errors)를 다루기 위해 Python 3.11에 ExceptionGroup과 except* 구문이 도입되었습니다.

ExceptionGroup과 except* 문법

# Python 3.11+ 다중 동시 예외 핸들링 예시
try:
    raise ExceptionGroup("Batch Job Multiple Failures", [
        ValueError("Invalid User ID format: -1"),
        TimeoutError("Connection to Redis pool timed out"),
        ValueError("Negative price detected"),
    ])
except* ValueError as eg:
    # ValueError에 해당하는 하위 그룹(subgroup)만 분할 처리
    for exc in eg.exceptions:
        print(f"Handled validation error: {exc}")
except* TimeoutError as eg:
    # TimeoutError에 해당하는 하위 그룹(subgroup) 처리
    print(f"Retrying network operation: {eg}")

⚙️ CPython 메커니즘 & 분할(Split) 동작

except*는 전통적인 except와 달리 매칭된 에러들을 하위 그룹(subgroup)으로 자동 분할(split)하여 각 블록에 전달합니다. 동일한 예외 그룹 내에서 여러 except* 절이 동시에 매칭될 수 있으며, 처리되지 않은 나머지 예외들은 자동으로 상위 호출자에게 재전파됩니다.

Modern Feature Python 3.11+ F18

asyncio.TaskGroup & 구조적 동시성 (Structured Concurrency)

기존 asyncio.gather는 한 태스크가 실패해도 다른 태스크가 취소되지 않고 고아(orphan)로 남아 소켓 누수를 유발했습니다. Python 3.11의 asyncio.TaskGroup은 구조적 동시성(Structured Concurrency)을 도입하여 하나의 작업이 실패하면 나머지 백그라운드 태스크들에 즉시 자동 취소(cancellation) 신호를 전파합니다.

async with asyncio.TaskGroup()

import asyncio

async def fetch_user(user_id: int): ...
async def fetch_orders(user_id: int): ...

async def run_pipeline():
    # 구조적 동시성 컨텍스트: 한 태스크라도 실패 시
    # 나머지 태스크에 즉시 자동 취소(cancellation) 신호 전달
    async with asyncio.TaskGroup() as tg:

from decimal import Decimal, ROUND_HALF_UP
from dataclasses import dataclass, field

@dataclass(frozen=True)
class CartItem:
    name: str
    price: Decimal
    quantity: int = 1

    @property
    def subtotal(self) -> Decimal:
        return self.price * self.quantity

class Cart:
    def __init__(self):
        self.items: list[CartItem] = []

    def add_item(self, name: str, price: Decimal, quantity: int = 1) -> None:
        self.items.append(CartItem(name=name, price=Decimal(str(price)), quantity=quantity))

    def calculate_total(self, discount_percent: Decimal = Decimal("0"), coupon_code: str = "") -> Decimal:
        raw_total = sum((item.subtotal for item in self.items), Decimal("0"))
        
        # 백분율 할인 적용
        if discount_percent > Decimal("0"):
            discount_amount = (raw_total * (discount_percent / Decimal("100"))).quantize(
                Decimal("1"), rounding=ROUND_HALF_UP

            raw_total -= discount_amount
            
        # 정액 쿠폰 할인
        if coupon_code == "VIP_10":
            raw_total -= Decimal("10000")
            
        return max(Decimal("0"), raw_total)

from pathlib import Path

class ConfigParseError(Exception): pass

def load_config(file_path: str | Path) -> dict[str, str]:
    path = Path(file_path)
    if not path.is_file():
        raise FileNotFoundError(f"Config file not found: {path}")

    config: dict[str, str] = {}
    try:
        with path.open("r", encoding="utf-8") as f:
            for line_no, raw_line in enumerate(f, start=1):
                line = raw_line.strip()
                if not line or line.startswith("#"):
                    continue
                if "=" not in line:
                    raise ConfigParseError(f"Malformed config line {line_no}: missing '='")
                
                key, val = line.split("=", 1)
                config[key.strip()] = val.strip()
    except UnicodeDecodeError as exc:
        raise ConfigParseError(f"Failed to decode config with UTF-8: {path}") from exc

    return config

from collections import Counter
from collections.abc import Iterable, Iterator
from datetime import datetime, timezone
from pathlib import Path

class LogPipeline:
    def parse_events(self, file_path: Path) -> Iterator[tuple[datetime, str]]:
        """제너레이터를 활용하여 메모리 점유율을 O(1)로 유지하는 스트리밍 파서"""
        with file_path.open("r", encoding="utf-8") as f:
            for line_no, raw_line in enumerate(f, start=1):
                line = raw_line.strip()
                if not line:
                    continue
                try:
                    parts = line.split("|")
                    ts = datetime.fromisoformat(parts[0]).replace(tzinfo=timezone.utc)
                    yield ts, parts[1].strip()
                except (ValueError, IndexError):
                    continue

    def process_logs(self, log_file_path: str | Path, target_events: Iterable[str]) -> Counter[str]:
        target_set = set(target_events)  # O(1) 멤버십 검사를 위한 해시셋
        path = Path(log_file_path)
        
        counter = Counter(
            event for _, event in self.parse_events(path)
            if event in target_set
        )
        return counter

import asyncio
import logging
from collections.abc import Sequence
import httpx

logger = logging.getLogger(__name__)

class AsyncWorker:
    def __init__(self, max_concurrency: int = 50, timeout: float = 10.0):
        self.semaphore = asyncio.Semaphore(max_concurrency)
        self.timeout = timeout

    async def _fetch(self, client: httpx.AsyncClient, url: str) -> str | None:
        async with self.semaphore:
            try:
                resp = await client.get(url, timeout=self.timeout)
                resp.raise_for_status()
                return resp.text
            except httpx.HTTPError as exc:
                logger.warning("Failed to crawl %s: %s", url, exc)
                return None

    async def crawl(self, urls: Sequence[str]) -> list[str]:
        results: list[str] = []
        async with httpx.AsyncClient() as client:
            # Python 3.11+ 구조적 동시성 TaskGroup 적용
            async with asyncio.TaskGroup() as tg:
                tasks = [tg.create_task(self._fetch(client, url)) for url in urls]

        for task in tasks:
            res = task.result()
            if res is not None:
                results.append(res)
        return results

import time
from functools import wraps

def memoize(ttl=60):
    cache = {}  # 크기 상한(maxsize) 없는 딕셔너리 -> 무한 메모리 누수!
    
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            # 1. unhashable 인자(dict, list) 들어오면 TypeError 크래시!
            # 2. 인스턴스 메서드에 적용 시 args[0](self)을 강참조하여 인스턴스 영구 누수!
            # 3. 비동기 코루틴 함수에 적용 시 반환된 coroutine 객체를 재사용하려다 크래시!
            key = (args, tuple(kwargs.items()))
            now = time.time()
            
            if key in cache:
                val, expire = cache[key]
                if now < expire:
                    return val
                    
            result = func(*args, **kwargs)
            cache[key] = (result, now + ttl)
            return result
        return wrapper
    return decorator
🔍 리뷰 체크포인트 (P0~P3 Checkpoints)
  • P0 Blocking 바운드 메서드 self 강참조로 인한 영구 메모리 누수: 데코레이터를 클래스 메서드에 적용하면 args[0]인 인스턴스 객체가 데코레이터 클로저의 전역 캐시에 영구 잔류하여 GC 수거 불가.
  • P0 Blocking Unhashable Arguments 크래시: 인자로 dict나 list가 전달되면 TypeError: unhashable type으로 런타임 즉시 크래시.
  • P1 Major 캐시 크기 상한(maxsize) 부재: 유니크한 파라미터가 유입될 때 캐시가 무한히 팽창하여 결국 OOM 발생. LRU 퇴출 정책 필요.
  • P1 Major 비동기 코루틴(async def) 미지원: async def 함수에 적용 시 이미 소비된 코루틴 객체를 반환하여 RuntimeError: cannot reuse already awaited coroutine 발생.

import collections
import inspect
import json
import time
from functools import wraps

class TTLCache:
    def __init__(self, maxsize: int = 1024, ttl: float = 60.0):
        self.maxsize = maxsize
        self.ttl = ttl
        self._data: collections.OrderedDict[str, tuple[any, float]] = collections.OrderedDict()

    def get(self, key: str):
        if key not in self._data: return None
        val, expire = self._data[key]
        if time.time() > expire:
            del self._data[key]
            return None
        self._data.move_to_end(key)
        return val

    def set(self, key: str, val):
        if len(self._data) >= self.maxsize:
            self._data.popitem(last=False)
        self._data[key] = (val, time.time() + self.ttl)

def memoize(maxsize: int = 1024, ttl: float = 60.0):
    cache = TTLCache(maxsize=maxsize, ttl=ttl)

    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            # 인자 안전 정규화 (unhashable 방어)
            try:
                key = json.dumps({"a": args, "k": kwargs}, sort_keys=True, default=str)
            except Exception:
                key = str((args, kwargs))

            cached_val = cache.get(key)
            if cached_val is not None:
                return cached_val

            result = func(*args, **kwargs)
            cache.set(key, result)
            return result
        return wrapper
    return decorator

import pickle
import os

class ReportEngine:
    def generate_report(self, script_name, params):
        """사용자가 지정한 리포트 스크립트를 실행하여 데이터 추출"""
        # 1. 경로 순회(Path Traversal): ../../etc/passwd 접근 가능
        script_path = os.path.join("/opt/reports", script_name)
        
        # 2. 쉘 인젝션: shell=True와 f-string 포맷팅 결합으로 RCE 발생
        cmd = f"python {script_path} --params '{params}'"
        subprocess.run(cmd, shell=True, check=True)

        out_file = f"/tmp/{script_name}.pkl"

import json
import subprocess
from pathlib import Path

class SecurityError(Exception): pass

class ReportEngine:
    BASE_DIR = Path("/opt/reports").resolve()

    def generate_report(self, script_name: str, params: dict, timeout_sec: float = 30.0) -> dict:
        # 1. 경로 순회(Path Traversal) 엄격 방어
        target_path = (self.BASE_DIR / script_name).resolve()
        if not target_path.is_relative_to(self.BASE_DIR):
            raise SecurityError(f"Directory traversal attack detected: {script_name}")
        if not target_path.is_file():
            raise FileNotFoundError(f"Report script not found: {script_name}")

        params_json = json.dumps(params)
        
        # 2. shell=False, 인자 리스트 전달 및 타임아웃 설정
        try:
            result = subprocess.run(
                ["python", "-S", str(target_path), "--params", params_json],
                capture_output=True,
                text=True,
                timeout=timeout_sec,
                shell=False,
                check=True
            )
            # 3. 안전한 JSON 역직렬화 (Pickle 완전 제거)
            return json.loads(result.stdout)
        except subprocess.TimeoutExpired as exc:
            raise TimeoutError(f"Report execution timed out after {timeout_sec}s") from exc
        except subprocess.CalledProcessError as exc:
            raise RuntimeError(f"Script failed with code {exc.returncode}: {exc.stderr}") from exc
