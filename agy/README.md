# Python 코드 리뷰 인터뷰 대비 (AGY)

Python 코드 리뷰 인터뷰 준비용 프레젠테이션(한국어, 38장)입니다. Junior·Intermediate·Expert 레벨별 평가 기준, 흔한 실수 12가지(Before/After 코드와 원리), Python 3.10~3.12+ 고급 기능, 레벨별 실전 코드 리뷰 문제 9문항(가상의 PR 코드, 리뷰 포인트, 모범 리뷰, 고친 코드)을 담고 있습니다.

- `index.html`: 외부 의존성 없는 단일 HTML 파일. 브라우저로 바로 열 수 있습니다.
- `verify_agy.py`: 표준 라이브러리만 쓰는 검증 스크립트(230개 항목). 외부 리소스 의존 여부, DOM 구조, 화면 기능, 콘텐츠 구성을 검사합니다.
- 조작: `←` `→` / `Space` 이동, `G` 전체 슬라이드 보기, `T` 목차, `F` 전체 화면, `D` 다크/라이트 테마

## 검증하기

```bash
python3 agy/verify_agy.py   # 저장소 루트에서 실행
```
